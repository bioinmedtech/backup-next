## 🏗️ Архитектура

### Компоненты (классы)
Все блоки оформлены как переиспользуемые PHP-классы в Components.php:

- **HeroSection** - главный экран с заголовком и CTA
- **ProblemsGrid** - сетка проблем пациентов
- **AdvantagesBlock** - блок преимуществ клиники
- **ServicesGrid** - топ-5 услуг с ценами
- **ChiefDoctor** - блок главного врача
- **Doctors** - слайдер с врачами
- **CasesSlider** - кейсы пациентов
- **ContactSection** - блок контактов и формы
- **Header** - шапка сайта
- **Footer** - подвал с логотипом и ссылками

### Данные и хранилище

**Статические данные** (в `config.php`):
- Константы клиники (CLINIC_NAME, CLINIC_PHONE и т.д.)
- `$brand_colors` - фирменная палитра
- `$services` - услуги (основные)
- `$faq_items` - часто задаваемые вопросы
- `$doctors` - информация о врачах
- `$problems` - типовые проблемы пациентов
- `$advantages` - преимущества клиники
- `$cases` - кейсы пациентов

**Динамические данные** (в `/data/*.json`, редактируются в админ-панели):
- `services.json` - переопределяет стандартные услуги
- `faqs.json` - переопределяет FAQ
- `reviews.json` - переопределяет отзывы
- `users.json` - учетные данные администраторов (создается автоматически)

## 🚀 Запуск

### Локально (для разработки)
```bash
cd /var/www/bioinmed-next
php -S localhost:8000
```
Откройте в браузере: http://localhost:8000

### На сервере (с nginx)
Конфиг виртуального хоста должен указывать на `/var/www/bioinmed-next` как root:

```nginx
server {
    listen 80;
    server_name next.bioinmed.ru;
    root /var/www/bioinmed-next;
    index index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php-fpm.sock;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

## 📝 Как добавить новый компонент

1. Создайте класс, наследующий `Component` в `Components.php`:
```php
class MyBlock extends Component {
    public function render() {
        return '<section>...</section>';
    }
}
```

2. В `index.php` добавьте:
```php
<?php
$block = new MyBlock($brand_colors);
echo $block->render();
?>
```

## 🔧 Как изменить данные

Все данные находятся в `config.php`. Отредактируйте нужный массив:

```php
$services = [
    [
        'name' => 'Новая услуга',
        'price' => 'от 5 000 ₽',
        // ...
    ],
];
```
