# PIN-защита сайта

## Описание
Сайт защищен красивой заглушкой с PIN-кодом. По умолчанию защита включена.

**PIN-код для входа:** `1290`

## Как работает
1. При попытке доступа к защищенной странице пользователь перенаправляется на `splash.php`
2. На странице заглушки предлагается ввести 4-значный PIN-код
3. При вводе правильного кода устанавливается сессия с доступом
4. Пользователь может беспрепятственно просматривать весь сайт

## Как отключить защиту
Чтобы отключить PIN-защиту, установите переменную окружения:
```bash
export PIN_PROTECTION_ENABLED=0
```

Или добавьте в `.env` файл:
```
PIN_PROTECTION_ENABLED=0
```

## Как изменить PIN-код
Отредактируйте файл `splash.php` и измените значение переменной `$correct_pin`:
```php
$correct_pin = 'ВАШЕ_ЧИСЛО'; // По умолчанию: 1290
```

## Особенности
- Красивый градиентный дизайн
- Плавные анимации
- Отзывчивый дизайн (мобильная версия)
- Удобный ввод PIN-кода с автоматическим переходом между полями
- Поддержка вставки полного PIN-кода через буфер обмена
- Автоматическая отправка при введении 4 цифр
