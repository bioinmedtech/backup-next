- Автоматическое создание users.json при первом запуске

- Удалена встроенная форма авторизации (было вместе с панелью)
- Добавлено автоматическое перенаправление на `login.php` для неавторизованных

1. Пользователь заходит на `/cabinet` или `/internal/cabinet.php`
2. Если не авторизован → перенаправляется на `/internal/login.php`
3. На странице входа вводит: логин `admin` и пароль `ChangeMe123!`
4. При успешной авторизации → создается `$_SESSION['cabinet_user']`
5. Пользователь видит админ-панель для управления контентом

### ✅ 2. Оптимизация цветовой палитры

**Проблема:** Логотип и некоторые элементы использовали основной цвет (#2fbdef), тогда как остальные элементы — более тёмные оттенки (#0077bd)

**Решение:** Унифицирована цветовая палитра для лучшей согласованности

#### Обновлены файлы:

##### a) `includes/components/Components.php`
- **Заголовки всех блоков:** #0077bd → **#2fbdef** (основной цвет)
- **Кнопки:** добавлены градиенты (от #2fbdef к #0077bd)
- **Footer сечения заголовков:** #0077bd → **#2fbdef**
- **Все h2, h3, h4 titles:** синхронизированы на основной цвет

**Примеры:**
```php
// Было:
<h2 class="text-3xl font-bold text-[#0077bd]">Заголовок</h2>

// Стало:
<h2 class="text-3xl font-bold text-[#2fbdef]">Заголовок</h2>
```

##### b) `includes/auth-toolbar.php`
- **Gradient toolbar:** #2fbdef → #0077bd (выделяет основной цвет в начале)
- **Shadow:** усилена для лучшей визуальной иерархии
- **Цвет значков:** белый (на фоне gradient)

```css
/* Было: #0077bd → #2fbdef */
/* Стало: #2fbdef → #0077bd */
background: linear-gradient(90deg, #2fbdef 0%, #0077bd 100%);
```

##### c) `prices.php`
- **Все заголовки категорий:** #0077bd → **#2fbdef** (8 секций)
- **Основной заголовок:** #0077bd → **#2fbdef**
- **Заголовки таблиц:** #0077bd → **#2fbdef**
- **Навигация (TOC):** цвет ссылок → **#2fbdef**
- **Общее количество замен:** 30+ вхождений

##### d) `internal/dashboard.php`
- **Header gradient:** #0077bd → #2fbdef (выделяет основной цвет)
- **Боковая навигация:** подсвечивается основным цветом
- **Кнопки action:** используют градиенты с основным цветом

## 🎨 Финальная цветовая палитра

```
Основной цвет (Primary):     #2fbdef (bright cyan)     ← ОСНОВНОЙ
Дополнительный (Secondary):  #0077bd (dark blue)        ← АКЦЕНТ
Успех (Success):             #00d084 (green)            ← ОК/СОХРАНЕНО
Тёмный текст:                #0f2749 (very dark blue)  ← ТЕКСТ
Светлый фон:                 #f2f8fb (very light blue) ← БОН
Граница:                      #dce8f5 (light border)     ← ГРАНИЦА
```

### Применение в коде:
- **Заголовки (h1, h2, h3, h4):** `text-[#2fbdef]`
- **Градиенты кнопок:** `from-[#2fbdef] to-[#0077bd]`
- **Активные элементы:** `bg-[#2fbdef]`
- **Ссылки:** `text-[#2fbdef] hover:text-[#0077bd]`
- **Фоны блоков:** `bg-[#f4f9ff]` или `bg-[#f2f8fb]`

## 📝 Примечания

### Важно для production:
1. **Измените пароль** с `ChangeMe123!` на реальный
   - Обновите `ADMIN_CABINET_PASSWORD` в `config.php` или env-переменную
   - Удалите старый `users.json`, чтобы он пересоздался с новым паролем

2. **Резервная копия users.json**
   ```bash
   cp /var/www/bioinmed-next/data/users.json /var/www/bioinmed-next/data/users.json.bak
   ```

3. **Проверьте permissions**
   ```bash
   chmod 755 /var/www/bioinmed-next/data
   chmod 644 /var/www/bioinmed-next/data/*.json
   ```

### Если форма входа не работает:
1. Удалите `users.json` - он будет пересоздан
2. Проверьте `/data` директорию доступна для записи
3. Посмотрите в `error.log` Apache
4. Убедитесь что `session_start()` вызывается в `login.php`

## 🔐 Безопасность
