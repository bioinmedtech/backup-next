## 🔄 Как работает версионность

### Пример: Сохраняем услугу "Остеопатия"

1. Входим в админ-панель (admin)
2. Кликаем "Услуги"
3. Редактируем описание услуги "Остеопатия"
4. Нажимаем "Сохранить услуги"

### Что происходит за кулисами:

```php
saveVersion('service', 'osteopathy', $serviceData);
// Создается файл:
// /data/versions/service_osteopathy.json
// {
//   "timestamp": "2024-12-15 14:30:45",
//   "data": { ...данные услуги... },
//   "user": "admin"
// }
```

**История хранит:** последние 50 версий каждой услуги

**В будущем:** можно реализовать откат версий через UI

## 🐛 Что делать, если что-то не работает

### "Я забыл пароль admin"

```bash
# Удалить файл пользователей
rm /var/www/bioinmed-next/data/users.json

# Зайти на /admin/login
# Система автоматически пересоздаст users.json с default admin/ChangeMe123!
```

### "Форма не сохраняется"

1. Проверить права доступа к `/data/`:
   ```bash
   ls -la /var/www/bioinmed-next/data/
   chmod 755 /var/www/bioinmed-next/data/
   ```

2. Проверить логи PHP-FPM:
   ```bash
   tail -f /var/log/php8.3-fpm.log
   ```

### "Версионность не работает"

```bash
# Проверить папка versions создана
ls -la /var/www/bioinmed-next/data/versions/

# Если нет, создать:
mkdir -p /var/www/bioinmed-next/data/versions
chmod 755 /var/www/bioinmed-next/data/versions
```
