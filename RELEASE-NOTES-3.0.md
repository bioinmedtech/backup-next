### 2️⃣ Система версионности контента (versioning infrastructure)

**Функция:** `saveVersion($entityType, $entityId, $data)`
**Сохранение:** `/data/versions/{entityType}_{entityId}.json`

#### Как это работает:

1. **Каждое изменение сохраняется**:
   ```
   /data/versions/service_osteopathy.json
   /data/versions/faq_123abc.json
   /data/versions/review_patient1.json
   ```

2. **Каждая версия содержит**:
   ```json
   {
     "timestamp": "2024-12-15 14:30:45",
     "data": { ...сохраненные данные... },
     "user": "admin"  // Кто редактировал
   }
   ```

3. **История хранится** (последние 50 версий на сущность)

4. **В будущем** можно реализовать откат версий через UI

## 🚀 Как использовать

### Вход в админ-панель

1. Перейдите на: `https://new.bioinmed.ru/admin`
2. Или: `https://new.bioinmed.ru/admin/login`
3. **Учетные данные по умолчанию:**
   ```
   Логин: admin
   Пароль: ChangeMe123!
   ```

### Управление услугами

1. Авторизуйтесь (роль admin или editor)
2. Кликните "Услуги" в боковом меню
3. Заполните/отредактируйте поля услуг
4. Нажмите "Сохранить услуги"
5. ✅ Версия автоматически сохранена в `/data/versions/`

### Управление пользователями (только admin)

1. Кликните "Пользователи" в боковом меню
2. **Создать пользователя:**
   - Введите логин, пароль, выберите роль
   - Нажмите "Создать"
3. **Обновить пользователя:**
   - Измените роль, установите новый пароль (опционально)
   - Нажмите "Обновить"

### Просмотр статистики

Главная страница админ-панели (/admin) показывает:
- Количество услуг, FAQ, отзывов, пользователей
- Красивые статистические карточки с градиентами

## 🔧 Технические детали

### Функции версионности

```php
// Сохранить версию
saveVersion('service', 'osteopathy', $serviceData);
// Результат: /data/versions/service_osteopathy.json

// Загрузить данные (с fallback)
$data = loadJsonOrDefault('/path/to/file.json', $defaultValue);

// Сохранить JSON файл
saveJson('/path/to/file.json', $arrayData);
```

### Роли и доступ

```php
// Проверить может ли редактировать контент
if (canEditContent($role)) { ... }  // true для admin, editor

// Проверить может ли управлять пользователями
if (canManageUsers($role)) { ... }  // true только для admin
```
