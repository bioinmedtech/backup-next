## 📋 Админ-панель: Что можно делать

### 1. Управление услугами

**Путь:** Админ-панель → вкладка "Услуги"

Можно редактировать для каждой услуги:
- ✏️ Название
- ✏️ Подзаголовок
- ✏️ Категория
- ✏️ Цена
- ✏️ Примечание к цене (например, "/час")
- ✏️ Короткое описание
- ✏️ Как проходит процедура
- ✏️ Для кого подходит

После редактирования → **Сохранить услуги** → сохраняется в `/data/services.json`

### 2. Управление FAQ

**Путь:** Админ-панель → вкладка "FAQ"

Можно:
- ✏️ Добавить вопрос
- ✏️ Добавить ответ
- ✏️ Отредактировать существующие

После сохранения → обновляется на сайте автоматически

### 3. Управление отзывами

**Путь:** Админ-панель → вкладка "Отзывы"

Можно редактировать:
- ✏️ Имя пациента
- ✏️ Проблему
- ✏️ Лечение
- ✏️ Результат
- ✏️ Оценку (1-5 звезд)

### 4. Управление пользователями (Admin only)

**Путь:** Админ-панель → вкладка "Пользователи"

Только администратор может:
- ✏️ Создать нового пользователя
- ✏️ Изменить роль (admin/editor/viewer)
- ✏️ Сменить пароль
- ✏️ Деактивировать пользователя

## 🔐 Роли пользователей

## 🛠️ Техническая информация

### Где хранятся данные?

```
/var/www/bioinmed-next/data/
├── services.json      ← Услуги (редактируются в админ-панели)
├── faqs.json          ← Часто задаваемые вопросы
├── reviews.json       ← Отзывы пациентов
└── users.json         ← Пользователи системы (создается автоматически)
```

### Форматы файлов

Все данные хранятся в JSON формате:

**Пример services.json:**
```json
[
  {
    "id": "hobilect-diagnostics",
    "name": "Комплексная диагностика HABILECT",
    "price": "от 9 900 ₽",
    "description": "Расширенная оценка организма...",
    "category": "diagnostics",
    "order": 1
  }
]
```

### PHP версия

- Требуется: PHP 7.4 или выше
- Используется: OOP, Session management, JSON processing
- Безопасность: bcrypt password hashing, input sanitization

## ⚠️ Важно знать

### Первый запуск

При первом открытии `/cabinet`:
1. Система проверит наличие `users.json`
2. Если файла нет → автоматически создаст с:
   - Username: `admin`
   - Password: `ChangeMe123!`
   - Role: `admin`

### Если забыли пароль

1. **Удалите** файл `/var/www/bioinmed-next/data/users.json`
2. Система пересоздаст его с паролем по умолчанию
3. Используйте `admin` / `ChangeMe123!`

### Изменение пароля

1. Откройте `/cabinet`
2. Нажмите вкладку "Пользователи"
3. Найдите вашего пользователя
4. Введите новый пароль в поле "Новый пароль"
5. Нажмите "Обновить"

## 📞 Поддержка

Если что-то не работает:

1. **Форма входа не открывается?**
   - Проверьте URL: `https://new.bioinmed.ru/cabinet`
   - Очистите кэш браузера (Ctrl+Shift+Delete)
   - Проверьте Apache error.log

2. **Неверный логин/пароль?**
   - Удалите `/data/users.json`
   - Попробуйте снова с `admin` / `ChangeMe123!`

3. **Не видно изменений на сайте?**
   - Очистите браузер-кэш
   - Обновите страницу (F5 или Ctrl+R)
   - Проверьте что сохранили изменения

4. **Ошибка прав доступа?**
   - Проверьте права на `/data`: `chmod 755 /var/www/bioinmed-next/data`
   - Проверьте права на файлы: `chmod 644 /var/www/bioinmed-next/data/*.json`
