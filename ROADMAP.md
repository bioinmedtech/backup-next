### 2️⃣ Real-time редактор с Live Preview

**Что:** Редактировать услугу на одной странице, видеть превью на другой

**Как работать:**
```
Админ-панель → Услуги → [Редактировать] → Split screen:
  - Левая часть: Форма редактирования
  - Правая часть: Live preview (обновляется при печати)
```

**Технология:**
- AJAX для отправки данных
- Fetch API для каждого изменения
- Jquery или Vanilla JS для обновления preview
- localStorage для кэша черновика (на случай потери соединения)

## 🎯 Приоритет 2 (Medium Priority - 2-4 недели)

### 4️⃣ Двухфакторная аутентификация (2FA)

**Что:** TOTP (Time-based One-Time Password) для безопасности

**Как работать:**
```
Админ → Настройки → Включить 2FA
```

**Ассоциировать:**
1. Показать QR код (Google Authenticator, Microsoft Authenticator)
2. Пользователь сканирует QR кодом в приложении
3. Подтверждает 6-значный код из приложения
4. При следующем входе: логин → пароль → код из приложения

**Библиотека:** PHPGangsta/GoogleAuthenticator

---

### 5️⃣ Резервное копирование (Backup)

**Что:** Автоматическое копирование данных

**Сценарии:**
- ✅ Ежедневное копирование в 03:00 (cron job)
- ✅ Ручное копирование (кнопка в админ-панели)
- ✅ Автоматический откат если данные повреждены

**Хранилище:**
```
/data/backups/
  ├── 2024-12-15-030000.tar.gz
  ├── 2024-12-14-030000.tar.gz
  └── manual-2024-12-15-143045.tar.gz
```

**Cron:**
```bash
0 3 * * * cd /var/www/bioinmed-next && tar -czf data/backups/$(date +\%Y-\%m-\%d-\%H\%M\%S).tar.gz data/
```
