## ⚠️ Важные замечания

### Безопасность
1. **Измените пароль** с `ChangeMe123!` на реальный
2. **Используйте HTTPS** (обязательно!)
3. **Регулярно** делайте резервные копии `/data/`
4. **Не делитесь** учетными данными

### Файловая система
```bash
# Важно для работы:
/var/www/bioinmed-next/data/         (директория доступна для записи)
/var/www/bioinmed-next/data/*.json   (файлы существуют и читаемы)
```

### Если что-то не работает
1. Удалите `/data/users.json`
2. Попробуйте войти снова
3. Если не помогает - смотрите `/var/log/apache2/error.log`
